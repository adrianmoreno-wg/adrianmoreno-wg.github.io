Lista de definicion

HTML
HTML (HyperText Markup Language o Lenguaje de Marcado de Hipertexto) es el lenguaje estandar utilizado para crear y estructurar el contenido de las paginas web
CSS
CSS (por sus siglas en ingles, Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje informatico que se utiliza para definir la apariencia y el diseño visual de los documentos escritos en lenguajes de marcado como HTML
DOM
El DOM (Document Object Model o Modelo de Objetos del Documento) es una interfaz de programacion de aplicaciones (API) que los navegadores web crean y exponen para representar documentos HTML, XML o SVG como una estructura logica en forma de arbol de nodos
